## v2.7.0 — 到点提醒与 Windows 版发布

并入 2.7.1~2.7.17。

### 新增

- 到点提醒。仅对写明具体时分的任务生效，仅写到哪一天的任务不提醒。
- 每条任务可设两档提前量，默认提前一小时与提前十分钟。取值可修改，每档可单独关闭。
- 到达截止时刻时不提醒。已完成、已搁置、已归档的任务，以及所属事件已搁置的任务，均不提醒。
- 新建任务时，若某一档已经过去，立即补发一条提示，写明实际剩余时间。
- 点击通知直接进入该任务所在的事件。总开关默认关闭，在「更多 → 提醒」中开启。
- Windows 桌面版随本版发布。同一页面内提供压缩包，解压后双击运行，无需安装，数据与手机版各自独立。
- 主线任务可以插在指定节点之后，任务动作面板在链上节点上新增相应入口。

### 修改

- 截止时间可以精确到分钟，日期面板新增选时间与清除时间入口。
- 时间选择器恢复为系统样式，仍为 12 格表盘，上午与下午可选。
- 界面锁定竖屏，不再支持横屏与翻转。
- 重置与清除的弹窗和提示文字经过简化。

### 修复

- 同一条提醒不再于每次打开应用时重复弹出。
- 到期日为当天的任务完整显示日期与时刻，空间不足时改用简写。
- 写明具体时分的任务，到点即计入逾期，无须等到次日；仅写到哪一天的任务仍按日判定。
- 已搁置的事件不计入逾期。
- 带钟点的截止日期在日历上重新显示圆环。

### 需要你手动做一件事

小米与 HyperOS 系统需为 GuideLine 开启「自启动」，否则手机重启后提醒将失效。
路径为「设置 → 应用设置 → 应用管理 → GuideLine → 自启动」。

## v2.4.0 — 同步页自动读取云端

并入 2.3.1~2.3.9、2.4.0、2.4.1。

### 修改

### 修复

- 标题栏的自动同步指示器此前在任何设备上都不可见，现已正常显示。
- 自动同步指示器不再出现首次可见、再次不可见的情况。
- 本机提交码不再停止刷新，也不再落后一代。
- 同步页面不再并列显示多个不同来源的提交码，整页只保留一种可比较的提交码。
- 缺口圆环拉成胶囊形状时不再露出接缝。
- 点阵屏上排不再长期空白，本机指纹可正常补全；两排改为显示同一种可比较的本机指纹。
- 内容未改动时，指纹不再随保存时间变化。
- 颜色值不再因字母大小写不同而被区别对待。
- 读屏软件不再念出点阵屏上的完整指纹，两排也不再被合并为一项。
- 陶土主题的说明改为与其余主题一致的写法。
- 回收站条目菜单的提示文字不再写作「更多」。
- 备份页的说明同时涵盖滚动备份与日快照。
- 「同步」区两条副标题的句式已统一。
- 「更多」页该入口的名称与页面标题现已一致。

## v2.2.0 — 数据安全修复

并入 2.1.1~2.1.11。本版不含新功能。

### 修改

- 导出页的条目数量与其他页面使用同一统计口径。
- 事件删除确认框统一使用同一份文案与任务数量。

### 修复

- 数据文件的版本高于本应用时，不再把该文件当作空数据交给后续流程，避免随之发生的静默丢数据。
- 工作区被更高版本锁定时，各类保存操作均受到保护，且不再报告为成功。
- 修正日期读取时年份补零丢失的问题。
- 不再接受日历上不存在的日期；同一日期在逾期判定中的结果保持一致。
- 删除项目确认框中的自动清除天数与实际保留期保持一致。
- 删除备份时改为按可用备份计数，确保始终保留至少一份可用的备份；读取不出来的备份不再计入可用备份。
- 备份损坏导致读取失败时，仍可逐份删除，直到保留最后一份可用备份。
- 日快照生成中断时，不再留下不完整的备份文件。
- 同一天内不再重复弹出离线提醒。
- 清理垃圾文件时不再被备份保留规则误拦。
- 隔离失败时的告警不再指向主文件本身。
- 任务列表中仅逾期条目使用弱化样式，其他档次的颜色恢复正常。
- 有到期日的任务不再被提示为「没有到期日」。
- 按紧迫度分组时，「未计入逾期」的范围与实际一致。
- 已搁置事件下的任务不再同时被标为「已逾期」与「未计入逾期」。

### 修复

- 推送后显示的提交码与实际写入远程的这一次一致，不再回读上一次记账中的提交码。
- 自动上传不会与进行中的上传重复执行。
- 本机没有活记录时，开机面板不再提供无法完成的按钮。
- 本机最后一次落盘时刻读取不到时，不再以当前时间顶替。
- 连不上 GitHub 的判断改由抛出错误的一方声明。

### 新增：到点提醒

这一版加的是**提醒**：只有你在任务上写了具体钟点（`10-03 18:00`），它才会在到期之前提醒你。

**怎么开**：「更多 → 提醒」把总开关打开（默认是关的）。

怎么提醒：

- 一条任务**两档**：默认**提前 1 小时**与**提前 10 分钟**。数值可以改，每档也可以单独关掉。
- **到点那一刻不提醒** —— 只在到期之前说一声。
- **只提醒写了钟点的任务**。只写到哪一天的不提醒：给"某天要做"编一个具体钟点，
  是编出来的信息。
- 新建任务时，如果"提前 1 小时"那档已经过去了，会**立刻补一条**
  「还有 25 分钟到期」—— 说的是真实剩余时间，不是那一档原本的提前量。
- **点通知直接落到那条任务所在的事件**；打开应用时的横幅与角标仍然保留。
