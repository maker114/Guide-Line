## v1.5.1 — 文案去括号，版本号不再漂移

只动文案与版本号口径，没有新功能。

- **界面与 README 去掉括号式补语**（实机反馈"文案要精炼"）：40 多处用户可见的句子
  改成顺口的说法 —— 「归档（含任务线）」→「归档整条任务线」、
  「另有 2 个已完成节点（点开看全过程）」→「…节点，点开看全过程」、
  「接下来 3 条待办（含没排期的）」→「…待办，含没排期的」、
  「分类（不装灵感）」→「分类，这里不装灵感」、「已保存（重新输入可替换）」→
  「已保存，重新输入可替换」、「背景图（实验性）」→「背景图 · 实验性」等。
  报错类文案里的「（原因）」保留，那是"正文 + 具体原因"的结构
- **修掉一处布局隐患**：合并编辑器的标题行原本是裸 `Text`，深色 + 1.6 倍字体 +
  窄屏下文案一长就溢出 19px；现在标题可缩并带省略号
- **README 顶上的「当前版本」滞后三个版本**（写着 1.3.0，实际已发到 1.5.0）：
  已改，并新增测试盯住「README ↔ pubspec ↔ CHANGELOG」一致
- 补打 `v1.2.0` 标签（CHANGELOG 有这一版，本机与远端都没有标签）；
  `docs/构建与发布.md` 的命令示例不再硬编码旧版本号，并补上发布脚本与两个坑

验收：`flutter analyze` 0 问题；`flutter test` 548 例全绿。
真机从 1.5.0+24 升到 1.5.1+25：`firstInstallTime` 仍是 2026-09-23（老数据零迁移），
启动无 `FATAL EXCEPTION` / `MissingPluginException`。

## v1.5.0 — 事件详情页改名 + 速记按钮两处修复

全部来自实机反馈（小米 15 Pro / HyperOS / Android 16）：

- **事件详情页顶栏 ⋮ 里补「重命名」**：点一下标题栏原地变成输入框（带确认 / 取消），
  与项目详情页同一套交互；事件名从此只在标题栏改，正文里那份重复的字段删掉
- **事件列表卡头不再写「最近 … · 接下来 …」**：只留"主线 3/4 已完成"这类进度记号
- **「时间与任务」试做后撤掉**：那两行摘要先是从列表卡头挪进详情页，做过四种排法，
  实机反馈"不好看"，于是连同取数与用例一起删除（不留零调用代码）
- **右下角「速记」不再像透明的**：底色从 `secondaryContainer`（强调色 22% 透明度、
  与页面底对比度最低 1.94）改成实心强调色
- **右下角「速记」出现更快**：原来挂在 `Scaffold.floatingActionButton` 槽位，
  入场是写死的 250ms + 旋转（对胶囊就是纵向压扁，实测 48 → 0.7 → 弹回 48）；
  现在自己摆位、自己进场：130ms 缩放 + 淡入，不转不回弹
- **任务行尾的到期日图标不再贴边**（`contentPadding.right` 0 → 12）

验收：`flutter analyze` 0 问题；`flutter test` 545 例全绿。
真机从 1.4.0+17 升级到 1.5.0+23：`firstInstallTime` 仍是 2026-09-23（老数据零迁移），
启动无 `FATAL EXCEPTION` / `MissingPluginException`。

安装包：`guideline-1.5.0.apk`（53.8 MB）
sha256：`2a1ed4204779c6359db02cd14df67838640879da70ea40696c237733a9cfe9e7`
