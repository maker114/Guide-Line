# GuideLine

本地优先的个人生活管理工具：**把「灵感」和「任务线」两条线管清楚**。
当前形态是 **Android 单机版**，用 Flutter 写，数据全部留在你自己的手机上。
当前版本 **1.5.1+25**，变更记录见 [`CHANGELOG.md`](CHANGELOG.md)、发行包见
[Releases](https://github.com/maker114/Guide-Line/releases)。

> 双端方案在服务器成本上卡住了，因此先把**单机体验**做扎实：
> 数据全部本地、可导出、可备份，不依赖任何第三方服务。
> 来龙去脉见 `docs/plan/mobile-v1-计划.md`。
> 电脑端成果已于 2026-09-24 **从工作区移除**，其完整源码仍可随时从
> git 历史取回：归档快照提交是 `786b143`，取法见下面「目录」一节。

## 功能

底部四个 Tab：

| Tab | 干什么 |
|---|---|
| **灵感** | 速记优先：随手扔进输入框，之后再决定分配 / 合并进项目 / 丢弃；可编辑、可打标签并按标签筛选、可长按多选批量处理 |
| **项目** | 项目树最多三层 + 目的 / 实现 / 日期 / 三态 / 标识色；灵感合并会写进项目「实现」 |
| **事件** | 每个事件是一条任务线：主线按顺序往下走，每个节点还能挂子任务。只有这两层 |
| **更多** | 接下来的任务、全部任务、全局搜索、归档区、主题与背景、备份与恢复、导出 / 导入 |

另外：**长按桌面图标 → 速记**，一键落到灵感输入框。

### 灵感：速记 → 归类 → 合并

- **逐条可编辑**：动作面板里的「编辑内容」点开就在列表里原地改，不弹对话框
- **多选批量**：长按任一条进入多选，或点「多选」；可一次分配 / 丢弃 / 删除
- **标签就是灵感的分类**：写的时候就能打标签，条目上点标签只看这一类；
  标签只是自己的标记，不影响归属项目、不影响归档与完成判定
- **一键合并**：合并编辑器里的「追加原文」把灵感原文**原封不动**作为新的一行
  接到项目「实现」末尾 —— 不自动改写、不润色；只改编辑框，仍要点保存才写盘
- **两侧都能发起合并**：项目详情页的待处理灵感可以直接点进同一个合并编辑器

### 项目：标识色

每个项目可以设一个标识色，十来种预设，不做任意取色；项目树标题前显示一小段色条。
刻意不放开成任意颜色：标识色的用途是"在树里一眼认出来"，近色反而更难分。
未设置就不显示，老数据不需要迁移。

### 项目「实现」：待办清单 + AI 整理 + 交接导出

「实现」由**两块并存**组成：**清单**是"要做什么"的拆分，**正文**是"整体怎么做"的说明。

- **实现清单**：可加 / 原地改 / 打勾 / 上移下移 / 删除，头部显示 `n/m 已完成`；
  旧的纯文本正文可以用「从正文拆成条目」一次拆开。这是个**显式动作**，不会在你打开时
  自动拆，而且拆分不改写正文。三条边界：顺序就是数组顺序、**不参与完成判定**，
  全勾完也不会把项目变成已完成；**与事件里的任务没有联动**
- **AI 整理成正文**：把清单交给模型，让它写出一段通顺的实现说明。
  这是本应用**唯一会联网**的功能，边界写在设置页里：只发项目名称 / 目的 / 清单条目，
  灵感原文、事件任务、其它项目一律不发；`apiKey` 存在系统安全存储里，
  **不进备份、不进导出**；提示词与模型返回的原文都不落盘。
  生成的结果**先给预览**、可编辑，确认后才写入正文 —— 模型可能编造清单里没有的东西
- **导出交接说明**：把项目生成一份 Markdown，含清单、正文、待处理灵感与事件任务线；
  预览可编辑后导出 `.md`，丢给电脑上的 AI 去实现。任务列表用的是 GitHub 语法
  `- [x]` / `- [ ]`，粘进 issue 也能直接用

### 全部任务：分组与紧迫度

- 分组三选一：**不分组 / 按事件 / 按紧迫度**，与状态筛选叠加使用
- 紧迫度**随日期由绿转红**，共 7 档：逾期→红、今天→橘红、3 天内→橙、
  5 天内→黄、7 天内→黄绿、7 天后→绿、**没排期→灰**；
  已完成 / 已搁置不再报警，一律走灰
- 到期日一律显示成**「绝对日期 + 剩余天数」**，例如 `2026-09-30（3 天后）` ——
  只给相对日不知道是几号，只给绝对日期又看不出还剩几天
- 刻意**不做「按项目」分组**：任务在数据上属于**事件**，而事件与项目之间没有关联字段。
  要支持它得先给事件加一个「所属项目」，那是数据契约变更，不在本版范围

### 任务行：能做的直接做，做不了的先说清楚

- 行内只留**一个图标**：点一下「设 / 改到期日」，**长按清除**；
  重命名 / 新建子任务 / 挪顺序 / 移到其它事件 / 归档 / 删除继续留在点这一行弹出的动作面板里 ——
  危险动作图标化会提高误触代价
- 还有未处理的子任务时，勾选框换成**锁形且不可点**，点它只解释原因。
  原来是"点了才弹错误"，用户得先撞一次墙才知道这一步做不了

### 界面与外观

- **输入一律在页面里直接写**，不弹对话框：项目 / 事件 / 任务的新建与重命名都是点一下原地编辑，
  速记框是一块可以连着记好几条的书写区，像系统备忘录
- **形状走一套 token**，写在一个文件里：`lib/ui/theme/shape_tokens.dart`。能点的用胶囊、
  装东西的用圆角矩形、只有图标的用正圆。改之前圆角是逐处写死的 `circular(12)`，
  想统一观感得翻遍所有控件；现在按用途命名、只改一处
- **7 套主题**：默认蓝 / 墨黑 / 松绿 / 陶土 / 梅紫 / 沙金 / 海松 —— 每套只定一个主色，
  其余交给 Material 3 推导，浅色深色都协调
- **背景图**：实验性功能。从相册选图后拷进应用私有目录，可调强度与模糊；
  还能**从图里取一个主色当主题**，按饱和度加权取样，而不是取"出现最多的颜色"——
  照片里最多的往往是灰墙和阴影
- 已完成 / 已搁置的任务**默认折叠下级**，主线任务与子任务在字号、底色、缩进上明确分层
- 界面里**不硬编码颜色**：所有颜色都从主题取，紧迫度这类语义色阶做成 `ThemeExtension`


## 数据与安全

没有云端，所以数据安全是一等公民：

- **单文件存储** `guideline.json`：临时文件 → flush → rename 的**原子替换**；
  跨实体操作天然全有或全无，比如合并灵感会同时改项目与灵感
- **备份轮转**：每次保存前留一份滚动备份，最近 10 份；每天第一份保存留日快照，最近 7 天。
  滚动备份可以在「备份与恢复」里**单独删除**，但**至少保留一份** ——
  没有云端时本地备份是唯一的安全网，"清空备份"应该是不可能完成的操作
- **损坏永不静默**：主文件读不出来就隔离现场，并自动从最近备份恢复
- **导出 / 导入**：整份数据导出为 `.json.gz` 经系统分享发出；导入前给摘要与二次确认，
  替换前自动留一份备份，导错了能退回
- 电脑端旧格式也能直接导入，指 v1 的四文档信封

## 目录

```
lib/
  core/       数据层与规则，纯 Dart，禁止 import Flutter
  features/   业务逻辑，Workspace 装全部业务规则
  app/        应用装配与动作门面
  ui/         界面，手机外壳加各 Tab
  platform/   平台适配，唯一允许出现平台判断与插件的地方
docs/         计划、数据契约、构建说明
test/         契约样本回归、规则、存储、架构边界、界面冒烟
tool/         一次性脚本，目前只有启动图标生成
```

电脑端那份归档工程已从工作区删除，省下约 263 MB；要翻旧代码用 git 历史：

```powershell
git show 786b143:archive/desktop-v1/lib/features/workspace.dart   # 单个文件
git ls-tree -r --name-only 786b143 -- archive                     # 归档里都有什么
```

分层边界由 `test/core/architecture_test.dart` 扫描源码守护。
