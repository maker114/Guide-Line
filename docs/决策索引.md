# 决策索引

> **这份文件只干一件事：让代码里的每一个 `ADR-xxx` / `Qxx` 都能查到"它当初裁定了什么、现在还算不算数、现行原文在哪"。**
> 它不是计划书，不是变更记录 —— 那些分别是 `docs/plan/*` 与 `CHANGELOG.md`。

## 0. 怎么用（先读这 6 行）

1. 在代码或文档里看到 `ADR-053`、`Q10` 这类编号 → 来本文件查"现行落点"那一列。
2. **权威原文永远在 `docs/spec/*`，不在本文件**。本文件只给指针，指向失效时才由本文件补位。
3. 编号**不重编、不复用**。裁定被推翻时，旧编号保留并标注"已被 ADR-xxx 取代"。
4. 新增决策：先看 §3 的规则，再在对应台账里加一行，**与引用它的代码改动放在同一个提交**。
5. 看不懂某个编号属于哪一套 → 直接看 §1。
6. 本文件的准确性由 `test/core/docs_consistency_test.dart` 守着（见 §4）。
