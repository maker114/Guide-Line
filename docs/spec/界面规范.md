# 界面规范：形状 · 版式 · 材质

> 依据：用户给的 Kimi 参考截图（对话框页 / 底部弹出面板 / 设置页 / 表格页 / 侧边抽屉）。
> 规则一句话：**能点的用胶囊，装东西的用圆角矩形，只有图标的用正圆。**

---

## 1. 三层形状

| 层级 | 形状 | 用在哪 |
|---|---|---|
| **胶囊** | 完全圆角（半径 = 高度一半） | 导航与标题、输入框、行为按钮、标签 |
| **圆角矩形** | 大圆角 | 内容分组卡片、任务框、快选芯片、底部面板 |
| **圆形** | 正圆 | 纯图标按钮、色点、头像 |

**反例（不要用胶囊）**：整屏/整行的容器、危险动作、文字标签本身。
圆角容器里再套圆角行会显脏；一屏全是胶囊会让层级消失。

## 2. 形状 token

新增 `lib/ui/theme/shape_tokens.dart`，**按用途命名，不按数值命名**。

| token | 值 | 用途 | 参考图对应 |
|---|---|---|---|
| `shapePill` | `StadiumBorder()` | 按钮、输入框、导航条、标签 | 顶部「快速 进阶」、底部「尽管问」、抽屉搜索框 |
| `shapeSheet` | 顶部 `circular(28)` | 底部弹出面板 | 第二张图的白色面板 |
| `shapeCard` | `circular(20)` | 内容分组卡片、任务框 | 设置页的三组白卡 |
| `shapeChip` | `circular(16)` | 卡片内的方形快选块 | 「拍照 / 照片 / 本地文件」 |
| `shapeField` | `circular(14)` | 表格/列表的值标签底 | 表格里的 `MOTOR_AUTO` |
| `shapeNested` | `circular(12)` | 卡片内次级块（**保留现值**） | 背景图强度预览 |
| `shapeDialog` | `circular(28)` | 对话框 | 与 Material 3 默认对齐 |

> 不要在控件里写 `BorderRadius.circular(n)` 字面量 —— 全部走 token。

## 3. 版式骨架

参考图里所有页面都是同一个骨架，照搬即可：

```
[ 胶囊导航条 ]        ← 顶部：胶囊标题 + 圆形图标按钮
[ 内容 ]
[ 分组卡片 ]          ← 白底 / 大圆角 / 卡片间距 ≥16
[ 小节标签 ]          ← 卡片外的小灰字（"订阅""个性化"）
[ 分组卡片 ]
...
[ 胶囊输入条 ]        ← 固定在底部时可加胶囊外壳
```

要点：

- **导航条**：胶囊标题（左）+ 圆形图标按钮（右）。抽屉用汉堡、对话用返回箭头。
- **分组卡片**：一组设置项 = 一张卡。**行与行之间用 1px 细线**（`outlineVariant`），
  但**首行上方、末行下方不画线**。卡片之间留 ≥16 的空隙，靠空隙分组，不靠标题线。
- **卡片外的小节标签**：放在卡片上方，小号 + 次要色（"订阅"那一行）。
- **底部输入条**：胶囊外壳 + 内部左圆 `+`、右圆 `语音`，中间是可输入区。
  **外层胶囊是形状，内层图标是正圆** —— 这是"胶囊套圆形"的典型用法。
- **底部快选芯片行**：横向一块，每个芯片是 `shapeChip` 圆角矩形（**不是胶囊**），
  左侧一个图标 + 一行文字，可横向滚动，超出屏宽要能滑。

## 5. 材质与颜色

参考图的层次是**"白卡 + 极浅灰底 + 更低对比的填充"**三级：

| 元素 | 承载色 | 说明 |
|---|---|---|
| 页面底 | `surfaceContainerLowest` / `surface` | 比卡片略灰，卡片才浮得起来 |
| 分组卡片 | `surfaceContainerLow` 或**白底 + 1px 描边** | 设置页是白卡；文件卡是浅描边 |
| 胶囊输入框 / 胶囊按钮 | `surfaceContainerHighest`（低透明度） | 「尽管问」「升级订阅」 |
| 快选芯片 / 值标签底 | `surfaceContainerHighest`（更低） | 比输入框更淡 |
| 强调色 | `colorScheme.primary` | 只给真正的动作，不要满屏上色 |

**硬约束（沿用现有约定）**：

- 一律取 `colorScheme` 的 role，**不写死灰值/白值**，浅色深色两套自动成立。
- 背景图开启时那层"保留底色"继续有效；胶囊与卡片用带透明度的 role，**不要实心白**，
  否则背景图会被卡片切成一块块。
- 分隔线用 `outlineVariant`，不要用 `dividerColor` 的默认黑。

## 6. 落地方式

1. **先建 token，再逐个替换控件**。
2. **`ListTile` 外面套有底色的 `DecoratedBox` 会报错**（水波纹画在最近的 `Material` 上）。
   要给整卡加底色/圆角，用外层的 `Card`/`Material` + `ListTile.tileColor`，别在 `ListTile` 外包一层。
3. **`Card` 的 `shape` 与 `margin` 要一起看**：只改 `shape` 不改 `margin`，圆角会被外边距吃掉一块。
4. **主题层能设的就别在控件里设**：`cardTheme` / `dialogTheme` / `inputDecorationTheme` /
   `bottomSheetTheme` 能覆盖的，优先在 `buildAppTheme()` 里设一次。
5. **回归测试**：跑「深色 + 1.6 倍字体下四个 Tab 不溢出」（`test/ui/app_smoke_test.dart`）。
   圆角不改布局，但改成胶囊后**按钮高度与内边距会变**，放大字体时最容易溢出。
6. **不引入新依赖**：`StadiumBorder` / `RoundedRectangleBorder` / `CircleBorder` 足够。
7. 形状与版式改动属 **修订位**（按 `CHANGELOG.md` 的版本规则）。

## 7. 数量口径（唯一出处）

同一个数在不同页面**必须用同一个算法、同一种写法**。过去出过的问题：事件卡写「主线 3/5」、
详情写「主线 3/5 已完成」，而且分子分母口径相反；「更多」页入口的副标题按"含已归档"算、
点进去的页面按"排除已归档"算。**范围限定词（含 / 不含）必须与算法一致。**

| 位置 | 写法 | 例子 |
|---|---|---|
| 标题栏 | **只给数字**，不带单位 | 项目 4 |
| 列表页副标题 / 页头 | 统一「共 N 条」，必要时在括号里写范围 | 共 12 条（含子任务） |
| 进度 | 统一「N/M 已完成」，分子分母同口径 | 主线 3/5 已完成 |
| 多选状态 | 「已选 N 条」 | 已选 3 条 |
| 搜索 | 「命中 N 条」；触到上限时要如实说 | 命中 100 条 · 只显示前 100 条 |
| 归档区 | 每个分区各自「共 N 条」 | 回收站 共 2 条 |
| 备份 | 「N 份可用备份」 | 3 份可用备份 |
| 紧迫度分组 | 分组头给「档名 N 条」 | 已逾期 3 条 |

三条硬约束：

1. **算法只有一处**：同一个数只能有一个计算函数，界面各处调它，不许各页自己数。
2. **范围限定词与实际算法一致**：写"不含已归档"就真排除，写"含子任务"就真含。
3. **说不出范围的数字不要给**：宁可写"共 N 条"，也不要给一个用户对不上号的数。
