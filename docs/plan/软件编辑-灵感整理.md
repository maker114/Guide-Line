## 五、形状规范（全应用）

依据：用户给的参考图。规则一句话：**能点的用胶囊，装东西的用圆角矩形，只有图标的用正圆。**

**14. 形状与版式** —— 完整规则见 [`docs/spec/界面规范.md`](../spec/界面规范.md)

规则一句话：**能点的用胶囊，装东西的用圆角矩形，只有图标的用正圆。**

新建 `lib/ui/theme/shape_tokens.dart`：

| token | 值 | 用途 |
|---|---|---|
| `shapePill` | `StadiumBorder()` | 按钮 / 输入框 / 导航条 / 标签 |
| `shapeSheet` | 顶部 `circular(28)` | 底部弹出面板 |
| `shapeCard` | `circular(20)` | 分组卡片、任务框、多行书写区 |
| `shapeChip` | `circular(16)` | 方形快选块 |
| `shapeField` | `circular(14)` | 卡片内字段 / 值标签底 |
| `shapeNested` | `circular(12)` | 卡片内次级块（保留现值） |
| `shapeDialog` | `circular(28)` | 对话框 |

版式骨架：**顶部胶囊导航条 → 分组卡片（行间 1px 细线，首尾不画）→ 卡片外小灰字小节标签 → 底部胶囊输入条。**
卡片之间留 ≥16 空隙，靠空隙分组。

- 按钮/输入/顶部标题 → 胶囊；任务框（现硬编码 `circular(12)`）→ `shapeCard`。
- 紧迫度色点、图标按钮 → **正圆**；整行容器（`ListTile`、页面底）**不加圆角**。
- 危险动作不做成醒目胶囊，留菜单里。
- 材质三级：页面底略灰 → 分组卡片白底或浅描边 → 胶囊/芯片浅灰填充。分隔线用 `outlineVariant`。
- 承载色一律取 `colorScheme` role，**不写死灰值/白值**；背景图开启时用带透明度的 role，不要实心白。
- 别在控件里写圆角字面量；`Card` 的 `shape` 与 `margin` 要一起看。
- 跑「深色 + 1.6 倍字体不溢出」用例。属**修订位**改动。
