# 桌面小组件 · 可行性结论

> **状态**：✅ 调研完成，**暂不实现**。本文只回答"能不能做、代价是什么"，不含代码改动。
> **实测日期**：2026-09-25 ｜ **机型**：小米 15 Pro（HyperOS OS3.0 / Android 16 / targetSdk 36）
> **验证件**：实测用一个**独立小程序**（临时放在 `.tools/widget-spike/`，在 `.gitignore` 内、全程不碰主工程）。
> 按"只留报告"的要求，**该程序连同它的截图、日志、反编译产物等中间产物已全部删除**，本文是唯一留存。
> **前情**：本功能在《软件编辑-灵感整理》（**已于 2026-09-27 移出工作区**）里一度定为"⛔ 放弃"；
> 2026-09-24 用户重启该需求并定下形态（见 §2）。结论取代当时的"放弃"。

---

## 1. 结论（一句话）

**技术链路全部成立，但小米的名录不让侧载 App 的原生小部件上桌面。**

- 想让它出现在小米桌面上 → 只能走 ①**上架小米应用商店 + 小部件审核**，或 ②**换第三方桌面**；
- ③小米官方的 **Widget Studio（MAML 主题小部件）** 能保证上桌面，但**读不到 App 数据**，"今天 / 逾期"这类计数做不出来。

代码侧没有问题：验证件的小部件声明与"能在小米桌面上显示"的知乎、支付宝**逐条一致**，系统也认它，渲染、数据通道、点击回传全部跑通。

## 4. 卡点：上不了 HyperOS 桌面

**卡点 1：`requestPinAppWidget()` 返回 `true` 但什么都不做。**
已排除：`com.android.launcher.permission.INSTALL_SHORTCUT`（已声明）、小米自己的
`com.miui.home.launcher.permission.INSTALL_WIDGET`（`protectionLevel=normal`，已声明且 `granted=true`）。
官方文档写明：小米把该方法劫持到**"只包含通过审核的 Widget"**的详情页 —— 未审核即静默失败。

**卡点 2：小部件中心不列我们。**
HyperOS 的小部件列表不是桌面画的，是小米自家 App `com.miui.personalassistant`（`widget://picker/...`）——
它本身是 MAML 小部件 SDK 宿主（日志里 `MaMlWidgetCompat` / `mamlWidgetSdk` / 云端 `maml/res` 包），主列表云端驱动。
它的「支持小部件应用」页末尾有 **「安卓小部件」** 分类（原生组件都归这里），里面是
**知乎 / CSDN / 哔哩哔哩 / 美团 / 一木记账** 等，**唯独没有我们**。

**已逐条对齐、仍然不出现的差异清单**（说明不是声明问题）：

- `previewImage` 位图（用验证件自己渲染导出后补上）
- 应用图标（验证件原本没有图标，已补）
- 安装来源（`pm install -i com.xiaomi.market`，与支付宝一致）
- **声明逐条对照**：反编译知乎 APK，它的小部件同样是 `exported=true` +
  `android:process=":widgetProvider"` + `miuiWidget=true` + `miuiWidgetRefresh=exposure` + `miuiWidgetVersion` ——
  和我们**完全一致**，它却出现在「安卓小部件」里
- 重启桌面进程、重启小部件中心进程：均无效

**门槛的解释**：小米的名录是**基于商店包解析**建立的 ——
官方流程为"APP 先上架小米应用商店 → [小部件开放平台](https://widget.xiaomi.com/) 拉取并解析该版本 APK → 提交审核"
（首次上传需先邮件 `miui-widget@xiaomi.com` 开通入口，平台面向**企业开发者账号**）。
侧载的自研 App 进不了这个名录。

## 5. 三条出路与代价

| 路线 | 能上小米桌面 | 能读 GuideLine 数据 | 代价 |
|---|---|---|---|
| **A. 原生小部件 + 上架小米商店 + 小部件审核** | ✅ | ✅ | 上架小米商店（企业开发者账号）→ 小部件开放平台提交 → 1~3 个工作日审核；首次需邮件开通入口 |
| **B. Widget Studio（MAML 主题小部件）** | ✅ | ❌ **读不到第三方 App 数据** | 桌面编辑器产出 `.mtz` + 设计师账号 + 审核；[系统变量清单](https://zhuti.designer.xiaomi.com/docs/widget-editor/systemtable/index.html)只有时间/天气/日程/健康/电量/流量等，没有第三方 provider 接口；只能做「跳转应用」按钮 + 系统信息 |
| **C. 第三方桌面**（Nova / Lawnchair 等，用标准 Android 选择器） | ✅ | ✅ | 要换桌面；只对愿意换桌面的用户成立 |

> 想让**带数据**的卡片出现在小米桌面上，只有 A 或 C。

## 6. 如果将来要做：先记下这些坑

**数据通道（推荐方案）**
- Dart 侧写一份精简快照 `files/guideline/widget_snapshot.json`（与 `guideline.json` 同目录，**原子替换**，
  复用 `lib/core/store/atomic_file.dart` 的做法），原生只读它、不解析主数据文件。
- 快照存 **`dueDays: ["2026-09-25", ...]`（待办任务的到期日列表）而不是两个计数**：
  小米上组件是**曝光刷新**，只存计数的话跨过零点"今天 / 逾期"会一直错到下次打开 App；存日期则每次刷新按当天重数。
- 分层：快照**结构生成**放 `lib/core`（纯 Dart，可在 `test/core` 断言口径与排序）；
  **写文件 + 通知刷新**放 `lib/platform`（`test/core/architecture_test.dart` 守分层）。
- 建议把"活跃任务"口径从 `lib/ui/more/all_tasks_page.dart` 抽到 `lib/core`，两处共用，避免以后改一处漏一处。

**小米/Android 硬约束**
- receiver 要 `android:process=":widgetProvider"`（独立进程，≤35M，不许拉起主进程）
- 曝光刷新：`miuiWidgetRefresh=exposure` + `miuiWidgetRefreshMinInterval`，并监听 `miui.appwidget.action.APPWIDGET_UPDATE`
- `android:label`（2~8 汉字、不等于应用名）、application 下 `miuiWidgetVersion`、receiver 上 `miuiWidget=true`
- 根布局 `@android:id/background` + 非全透明背景色；圆角自己加（兼容非小米）
- **深色模式只能 XML 静态适配**（`values-night`）；组件**吃不到 Flutter 主题**，配色要单独一套并手动同步
- `previewImage`（位图）+ `previewLayout` + `targetCellWidth/Height`；清数据后要能退回默认视图
- 尺寸：110dp 会重叠（见 §3），min 尺寸建议 150dp 上下或去掉 footer

## 7. 验收手段（下次直接用）

```powershell
$adb = "$env:LOCALAPPDATA\Android\sdk\platform-tools\adb.exe"
& $adb -s <序列号> shell "dumpsys appwidget | grep -i -A6 <包名>"      # provider 是否登记 / 是否被绑定
& $adb -s <序列号> shell "am force-stop com.miui.home"                 # 逼桌面重拉小部件列表
& $adb -s <序列号> shell "am start -a android.intent.action.MAIN -c android.intent.category.HOME"
& $adb -s <序列号> shell screencap -p /sdcard/p.png ; & $adb -s <序列号> pull /sdcard/p.png .\p.png
& $adb -s <序列号> shell "uiautomator dump /sdcard/ui.xml"             # 原生界面能读到文字
& $adb -s <序列号> logcat -d -s <自己的 TAG>:V
```

**别绕道（都已实测确认）**

| 想做的事 | 结果 |
|---|---|
| `adb shell input tap/swipe/keyevent` | `SecurityException: INJECT_EVENTS` —— 真机不给，点击类验证只能本人操作 |
| `uiautomator dump` 读 Flutter 界面 | 读不到（语义树不暴露）；但**读小米小部件中心这类原生界面没问题** |
| `settings put system font_scale` | `SecurityException: WRITE_SETTINGS` —— 字号只能本人手动改 |
| `adb exec-out screencap -p > x.png` | PNG 会被按文本重写换行弄坏，必须"手机存文件 → `adb pull`" |
| `adb install` 新包 | `INSTALL_FAILED_USER_RESTRICTED` → `pm install -i com.android.vending -r /data/local/tmp/x.apk` |
| `flutter` 命令在管道里 | 可能卡死，输出重定向到文件再读（见 `docs/构建与发布.md` §2） |
| 独立 Gradle 工程构建 | 需要写工作区之外的 `~/.gradle`（本会话沙箱一度拒绝，放开后正常） |
