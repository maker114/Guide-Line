## 批 10 · 收尾（装机走查）

1. `flutter analyze --no-pub`（0 问题）+ `flutter test --no-pub`（全绿）。
2. **构建时必须显式给版本号**：`android/local.properties` 会缓存
   `flutter.versionName` / `flutter.versionCode`（本机缓存里现在是 `1.4.0` / `16`，
   而 `pubspec.yaml` 是 `1.3.0+4`）—— 不显式指定就会打出一个与界面上显示的版本号
   不一致的包，而且全程不报错（《构建与发布》§6.4）。
   ```powershell
   flutter build apk --release --build-name=1.3.0 --build-number=4
   ```
3. 安装与启动（真机 `51dabb34`，adb 在
   `C:\Users\lenovo\AppData\Local\Android\Sdk\platform-tools\adb.exe`，不在 PATH 里）：
   ```powershell
   adb -s 51dabb34 install -r build\app\outputs\flutter-apk\app-release.apk
   adb -s 51dabb34 shell am force-stop com.maker.guideline
   adb -s 51dabb34 shell am start -a com.maker.guideline.SHORTCUT_CAPTURE -n com.maker.guideline/.MainActivity
   adb -s 51dabb34 shell dumpsys package com.maker.guideline | Select-String versionName
   adb -s 51dabb34 shell screencap -p /sdcard/p.png ; adb -s 51dabb34 pull /sdcard/p.png shot.png
   ```
   截图只能走"手机存文件 → `adb pull`"（`exec-out` 会被 PowerShell 重写换行、PNG 变坏）。
